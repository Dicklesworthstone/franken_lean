# Which crates' lib/bin targets can reach a released artifact.
#
# This file is the POLICY half of the classification. The target set and each
# target's kind are derived mechanically by `derive::derive_targets`; whether a
# crate ships is a judgement, so it is declared here and `derive::classify`
# blocks on any derived crate this file does not cover. An unclassified crate
# is a hard gap, never a default: a shippable target misfiled as
# development-only is invisible to the very gate built to catch it.
#
# Note what this file does NOT control. A test, bench, example or build-script
# target never ships regardless of what is written here — that is mechanical,
# enforced in `classify`, and not overridable by policy.
#
# shippable        = part of the product surface (§4: the toolchain binaries,
#                    the embeddable library, the MCP server)
# development-only = tooling, harnesses and rigs, absent from every release
