# The Tribunal campaign owner matrix (plan §18.2–18.3; bead fln-td9, framework 2 of 6).
#
# Two row kinds, pipe-separated, '#' comments:
#
#   adapter <domain> | <family> | <owner bead> | <state> [| <evidence>]
#   invariant <campaign id> | <FL-INV id> [| <FL-INV id> ...]
#
# ADAPTER rows make production adapters mandatory on their subsystem owners: a
# campaign family is not done when the framework exists — it is done when the
# owning subsystem's adapter is active and green against named evidence. States:
#   registered  — declared here only. Satisfies NO downstream gate.
#   active      — wired into the owner's rig; evidence names the wiring.
#   green       — active and currently passing; evidence names the run.
# A registered-but-inactive adapter cannot satisfy its downstream gate, and the
# validator refuses evidence-less active/green rows.
#
# INVARIANT rows bind campaign ids to the FL-INV ids they feed (td9's design law):
# every FL-INV-01..07 is covered, and a campaign run that merely executes without
# killing its named mutant is a failure, never evidence.
#
# Domains are the bead's own seven: grammar-source (Vellum), kernel-terms (the
# kernel differential rig), olean-read / olean-write (the W2 codecs), vm-opcodes
# (Golem/FLBC), cas-manifest (W8 Ledger), server-editor (replay/protocol rigs).
#
# Today's honest state: every adapter is `registered`. Nothing here is active, and
# no downstream gate may treat this file as satisfaction. Rows move to active/green
# only with evidence, and the suite checks both directions.
